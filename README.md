# Pia Rahman | AI Product Manager Portfolio

I'm an AI Product Manager and two-time co-founder. Over 10+ years I've built products across fintech, accounting software and financial services. This repository holds my product portfolio website.

**Live site:** https://mpiarahman16.github.io/portfolio/ *(update this link once GitHub Pages is on)*

## What's inside

- **KnewSooner (flagship case study):** an AI guide to Canadian money for newcomers covering banking, credit, borrowing and taxes. It shows discovery, eval-driven development with gold datasets and rubrics, and results:
  - 12 weeks from research to first release
  - +20% engagement within 3 months
  - +30% AI answer accuracy within 8 weeks
  - +25% sprint delivery predictability over 4 months
- **Risk Lens:** a working prototype I built with Claude Code. Live at [mpiarahman16.github.io/risklens](https://mpiarahman16.github.io/risklens/).
- **Your Village:** AI-assisted onboarding that cut time to first connection by 40% and raised week-one retention by 20%.
- **BlackLine:** data products for an accounting platform, a $500K/yr cost reduction, and the SAP certification of the acquired FourQ intercompany product.
- **Estée Lauder:** an enterprise rollout of Braze customer engagement with 60+ stakeholders, cutting costs by 30% in 6 months.
- **Experience:** JPMorgan Chase Wealth Management, Northern Trust, Chateaux.

## How it's built

The site is a single self-contained `index.html` file with no build step and no dependencies. Fonts come from Google Fonts and diagrams render with Mermaid. It supports light and dark mode and works on phones.

I built it with Claude, and I use Claude and Claude Code to prototype product ideas before engineering commits a sprint.

## Run it locally

Download or clone the repository and open `index.html` in any browser.

```bash
git clone https://github.com/mpiarahman16/portfolio.git
cd portfolio
open index.html   # on Windows: start index.html
```

## Publish with GitHub Pages

1. Go to **Settings → Pages** in this repository.
2. Under **Source**, choose **Deploy from a branch**.
3. Select the `main` branch and the `/ (root)` folder, then click **Save**.
4. After a minute or two, the site is live at `https://mpiarahman16.github.io/portfolio/`.
